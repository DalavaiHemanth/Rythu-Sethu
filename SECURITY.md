# Security Policy

## Supported Versions

Only the latest version of Rythu Sethu is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| < 1.0.0 | Yes       |

## Reporting a Vulnerability

We take the security of Rythu Sethu seriously. If you believe you have found a security vulnerability in this project, please report it to us responsibly.

**Do not open a public issue.** Instead, please send an email to the project maintainers.

Please include the following information in your report:
- A description of the vulnerability and its potential impact.
- Detailed, step-by-step instructions on how to reproduce the issue.
- Any proof-of-concept exploit code or screenshots if available.

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a security release to patch the issue.
